# The Sales Falcon — Carousel ideas 11–20

Same format as 01–10: 7–9 slides, a Malayalam–English hook, one practical framework, and a "playbook" DM CTA. Any illustrative story is labelled "(Illustrative example.)".

---

## 11-price-objection
**Hook (slide 1):** "Price കൂടുതലാണ്" — discount കൊടുക്കും മുൻപ് ഇത് വായിക്കൂ.
**Flow:** Why "price" is rarely the real problem → 3 replies that don't cut price (ask "compared to what?", break the cost into a per-day amount, show what it costs them to do nothing) → when a discount does make sense → recap.
**Caption angle:** Discount ആദ്യം കൊടുക്കുന്നവർ margin-ഉം respect-ഉം ഒരുമിച്ച് കളയുന്നു.
**CTA:** Price objection scripts → "playbook"

## 12-referral-ask
**Hook:** Happy customer ഉണ്ട്. Referral ചോദിച്ചിട്ടുണ്ടോ?
**Flow:** Why most people never ask → the best moment to ask (right after a win, not at billing) → a 2-line script → make it easy (a ready-made WhatsApp forward) → thank-you loop.
**Caption angle:** Referral leads close faster, but only if you ask.
**CTA:** Referral request message → "playbook"

## 13-quotation-ghosted
**Hook:** Quotation അയച്ചു. പിന്നെ silence.
**Flow:** Day 2 check-in (a question, not "seen ആയോ?") → Day 5 value add → Day 10 "breakup message" ("ഈ file close ചെയ്യട്ടേ?") → why the breakup message gets the most replies.
**Caption angle:** A polite "No" is better than a silent "Maybe".
**CTA:** Breakup message template → "playbook"
*(Different from 09: this one is only about the after-quotation stage and the breakup message.)*

## 14-voice-note-vs-text
**Hook:** WhatsApp-ൽ voice note അയക്കണോ, text അയക്കണോ?
**Flow:** When text wins (prices, details, first contact) → when a voice note wins (relationship, explaining, recovering a deal) → the 30-second voice note rule → 3 mistakes (2-minute notes, background noise, no text summary).
**Caption angle:** The channel is part of the message.
**CTA:** Comment "voice" or "text": which do you prefer?

## 15-gatekeeper
**Hook:** "Sir busy ആണ്, പിന്നെ വിളിക്കൂ."
**Flow:** Treat the receptionist or assistant as an ally, not a wall → use their name → give a specific reason for the call → ask for the best time, not "is he free?" → follow up through them.
**Caption angle:** The gatekeeper decides more than you think.
**CTA:** Gatekeeper opener → "playbook"

## 16-ask-for-the-order
**Hook:** Meeting നന്നായി പോയി. പക്ഷേ order ചോദിച്ചില്ല.
**Flow:** Why salespeople hesitate → 5 low-pressure closing questions ("ഏത് date-ൽ start ചെയ്യാം?", "1 pack or 3?", and so on) → reading the buying signals → what to do after "let me think".
**Caption angle:** If you don't ask, the answer is always no.
**CTA:** Save it and use it in your next meeting.

## 17-give-get-negotiation
**Hook:** ഒന്നും വാങ്ങാതെ ഒന്നും കൊടുക്കരുത്.
**Flow:** The give–get rule → 4 trades to ask for in return for a discount (advance payment, a longer contract, a referral, a case study) → how to say it politely → before/after dialogue.
**Caption angle:** Negotiation is a trade, not a surrender.
**CTA:** Give–get cheat sheet → "playbook"

## 18-fresher-mistakes
**Hook:** Sales-ൽ ആദ്യ വർഷം ഞാൻ ചെയ്ത 5 mistakes.
**Flow:** Talking too much → pitching before understanding → chasing everyone instead of qualifying → not writing anything down → taking rejection personally → one fix for each.
**Caption angle:** Every top performer made these. The fast ones fixed them early.
**CTA:** Tag a new salesperson on your team.

## 19-existing-customer-upsell
**Hook:** ഏറ്റവും എളുപ്പമുള്ള sale ഇപ്പോഴത്തെ customer-ന്റേതാണ്.
**Flow:** A new customer vs a repeat customer (effort and trust) → a 90-day check-in call → spotting the next need → cross-sell vs upsell with simple examples → not being pushy.
**Caption angle:** Stop only hunting. Start farming.
**CTA:** Customer check-in script → "playbook"

## 20-year-end-push
**Hook:** December-ൽ deals close ആകില്ല? ശരിക്കും?
**Flow:** Why year-end works (budgets left over, new-year plans) → 3 moves for the next 4 weeks (revive stalled deals, plan January meetings now, ask for referrals at year-end) → a simple December calendar → a January head start.
**Caption angle:** Timely: post in the last week of November.
**CTA:** Year-end revival message → "playbook"
